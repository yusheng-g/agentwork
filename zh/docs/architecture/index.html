# Layers

Event ≠ truth

idempotentconditional-tx

总线只是唤醒提示；每个状态迁移都是带条件的 DB 事务，重放下幂等。

// bus.Publish(goal.status, {active→review})
// → daemon 重读 DB, 检查 guard, 迁移
// → 重放安全: 同一事务, 同一结果

机器执行器（PULL）

run.pollpull-modelJSON-RPC

agentwork connect 持有一条 JSON-RPC 长连接，拉取工作（run.poll）；它执行运行并托管每 agent 的 chat bridge——spawn CLI，原样转发 ACP 帧。

machine → daemon:  run.poll
daemon → machine:  { run: r9k1, cancels: [] }
machine:          runtime.Open(spec) → spawn CLI

按 run 工作树

ephemeralbare-reporecovery

~/.agentwork/runs/<runID> 临时 git worktree，挂在每 domain 的 bare repo 上；崩溃恢复时重放终态 run 并在启动时重算 attention。

~/.agentwork/runs/r9k1/      # git worktree
~/.agentwork/repos/<domain>/  # bare repo（真相）

协调器

derivedowner-attention

派生的 OwnerAttention（集成 / 恢复 / user_action）在恰好有活干时唤醒 owner——绝不被噪声唤醒。

// 子目标冲突 → OwnerAttention:integration
// run 卡住    → OwnerAttention:recovery
// 人工回复    → OwnerAttention:user_action
