# Layers

Event ≠ truth

idempotentconditional-tx

The bus is a wakeup hint; every transition is a conditional DB transaction, idempotent under replay.

// bus.Publish(goal.status, {active→review})
// → daemon re-reads DB, checks guard, transitions
// → replay safe: same tx, same result

Machine executor (PULL)

run.pollpull-modelJSON-RPC

agentwork connect holds a persistent JSON-RPC link and pulls work (run.poll). It executes runs and hosts the per-agent chat bridge — spawns the CLI, relays ACP frames unparsed.

machine → daemon:  run.poll
daemon → machine:  { run: r9k1, cancels: [] }
machine:          runtime.Open(spec) → spawn CLI

Per-run worktrees

ephemeralbare-reporecovery

~/.agentwork/runs/<runID> ephemeral git worktrees against per-domain bare repos. Crash recovery replays terminal runs and re-derives attention at startup.

~/.agentwork/runs/r9k1/      # git worktree
~/.agentwork/repos/<domain>/  # bare repo (truth)

Coordinator

derivedowner-attention

Derived OwnerAttention (integration / recovery / user_action) wakes the owner exactly when there is work for it — never on noise.

// sub-goal conflict → OwnerAttention:integration
// stuck run      → OwnerAttention:recovery
// human reply    → OwnerAttention:user_action
